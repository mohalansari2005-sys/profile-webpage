## Who I am

I'm a software engineer based in Riyadh, currently interning at Majara
as a product engineering intern, where I work on Python backend
services, REST APIs, and new product prototypes for a B2B platform.
Before that I spent a few months in business development at SEET
(صيت), a Riyadh marketing agency, which is where I picked up the habit
of treating "what does the other side actually need" as the first
question in any project, technical or not.

Most of my hands-on engineering experience so far centers on backend
work: Python, FastAPI, SQLAlchemy, REST API design, and the
infrastructure around that (Postgres, Redis, Celery, Docker, pytest).
I'm comfortable moving from a requirements conversation to a working
system, and I care about the parts of backend work that don't show up
in a demo — idempotency, retries, multi-tenancy, and what happens when
an external dependency misbehaves.

This portfolio site's chat feature is a deliberate exception to how I
otherwise approach projects: where I usually default to the simplest
tool that solves the problem, the chat feature is a dedicated learning
exercise, so I chose heavier architecture on purpose — retrieval over
this markdown corpus, agent orchestration with LangGraph, and
self-hosting the backend on my own infrastructure — specifically to
get hands-on practice with those pieces rather than to keep the site
itself minimal.
