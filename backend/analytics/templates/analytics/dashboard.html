How to read this

  • A visitor is a distinct salted IP hash, the same key the chat log uses. People sharing an IP (an office, a mobile carrier) count once; one person on two networks counts twice.
  • Only browsers that run JavaScript are counted, which leaves out most bots; visitors with strict ad or tracker blockers may be missed too.
  • Page views start on the day this shipped; there is no history before it. Chat numbers go back to the first logged question.
  • Days run midnight to midnight in {{ stats.tz }}. "Questions refused" counts the bot declining a question; service errors (the AI provider was unavailable) are counted on their own and are not refusals.
  • Chat numbers, charts and the latest questions count only questions asked from the live site. Synthetic ones are left out: the daily canary and other scripted checks (no Origin header) and Vercel preview deployments. Previews send no page views either.
  • To stop counting your own visits, open the site once with ?analytics=off in that browser; ?analytics=on undoes it.
